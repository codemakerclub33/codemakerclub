## Ce acoperă Modulul 1 (harta Scratch)

Fiecare lecție are poveste, 2–3 personaje sincronizate (pe rând, prin `așteaptă` și mesaje) și scripturi-model. Tiparul lecțiilor e în `../_blocuri-pe-lectii.md`.

| Zonă Scratch | Unde |
|--------------|------|
| Interfață, scenă, decoruri, costume | L1–L2 |
| Mișcare (rotire, glisare, poziții) | L3 |
| Evenimente: tastă, click, decor, mesaje (`difuzează`, `când primesc`) | L4 |
| Aspect: balon, mărime, efecte de culoare | L5 |
| Sunet: volum, efecte audio, oprire, microfon | L6 |
| Coordonate x și y (`modifică`, `setează`) | L7 |
| Control: `la infinit`, `dacă`, `dacă … altfel`, `așteaptă până când`, `repetă până când`, `stop` + 2 condiții din Detectare | L8 |
| Mini-proiect cu toate categoriile | L9 |
| Completare + prezentare + insignă (Gala personajelor) | L10 |

**Total blocuri noi în M1:** 53.  
**Extensii** (Muzică, Stilou): nu în M1.

## Note profesor

1. **Steagul** se folosește din L1 ca „regulă de bază”.  
2. **Minim** = personajul 1 cu cel puțin 8 blocuri diferite; **Complet** = personajul 2; **Bonus** = personajul 3. Cine rămâne în urmă salvează la Minim.  
3. La L6 evenimentul cu microfon (`când [intensitatea sunetului] >`) e doar la Bonus, pentru că nu toate calculatoarele au microfon.  
4. La L10 prezentările sunt scurte (1–2 minute, maximum 10 copii). Insigna se primește cu Minim.  
5. **Modulul 2** se suprapune parțial cu Modulul 1 (`dacă`, `forever`, mesaje) și trebuie regândit.
