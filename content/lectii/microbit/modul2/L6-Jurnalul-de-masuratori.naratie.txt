Lecția șase. Jurnalul de măsurători.

Astăzi înveți să ții mai multe numere într-o singură cutie și faci Jurnalul de măsurători: placa notează temperatura de câte ori apeși A, iar apoi îți citește jurnalul și calculează media și maximul. Fișierul se numește Prenume, linie jos, Nume, linie jos, M B doi, linie jos, L zero șase.

Obiectivul. La finalul orei folosești o listă: adaugi valori, le citești pe rând cu For index și calculezi o medie și un maxim. Minim: A notează temperatura în listă, B o citește pe rând, cu cel puțin opt blocuri diferite. Complet: partea a doua, în care A și B împreună calculează media și maximul măsurătorilor, cu cel puțin șase blocuri diferite.

De ce contează. O variabilă obișnuită ține un singur număr. Dar un meteorolog notează temperatura în fiecare oră, nu doar o dată. El are nevoie de un caiet. O listă este caietul programului: ține câte numere vrei și le poți citi pe rând.

Ce face fiecare bloc de azi. Empty array este o listă fără nimic în ea, o pui într-o variabilă cu Set. Add value to end of adaugă o valoare la sfârșitul listei. Length of arată câte valori are lista. Get value at citește valoarea de la poziția dată, iar prima poziție este zero. Numele pot diferi puțin în editor, caută blocurile după formă. Din lecțiile trecute știi deja On start, Show number, Show string, Show icon, Pause, Clear screen, On button pressed, Temperature, For index, Set, Change, If then, comparațiile, scăderea și împărțirea.

Primul pas. Jocul Caietul, fără calculator. Un copil este caietul. Ceilalți spun un număr, iar caietul îl adaugă la sfârșit. Apoi cineva întreabă: ce este la poziția zero, adică primul, ce este la poziția unu, adică al doilea. Atenție: prima poziție este zero, nu unu, ca la coordonatele de pe ecran.

Al doilea pas. Creăm lista și adăugăm valori. Proiect nou. Creezi variabila masuratori. În On start, Set masuratori la o listă goală. Blocul este în Advanced, Arrays. La butonul A, Add value to end of masuratori cu temperatura, apoi o bifă, pauză și Clear screen.

Al treilea pas. Citim lista, For index. La butonul B citim toate valorile, una câte una, cu For index. O listă cu trei valori are pozițiile zero, unu și doi, deci bucla merge de la zero la length minus unu. Pe fiecare poziție: Show number Get value at index, pauză, Clear screen. Înainte de buclă punem un If, length mai mare decât zero, ca să nu citim o listă goală.

Al patrulea pas. Jurnalul, pentru Minim. Reunești totul. Testezi: apeși A de trei ori, poți ține placa în mână ca să se schimbe temperatura, apoi B: vezi cele trei valori.

Al cincilea pas. Complet. Media și maximul. La A și B împreună calculăm două lucruri din listă. Media este suma valorilor împărțită la numărul lor: la fiecare poziție, Change suma cu valoarea, apoi suma împărțită la length. Maximul este cea mai mare valoare: pornim cu maxim zero, iar dacă o valoare este mai mare decât maxim, o salvăm în maxim. Creezi variabilele suma și maxim.

Greșeli frecvente. B nu arată nimic: lista este goală sau lipsește Set masuratori la listă goală. Prima valoare lipsește: bucla începe de la unu, prima poziție este zero. Placa se blochează la ultima valoare: bucla merge până la length, nu până la length minus unu. Media este prea mare: suma nu este zero la început. Maximul este zero: If valoare mai mare decât maxim este în afara buclei. Valorile par greșite: placa s-a încălzit în mână, așteaptă puțin între apăsări.

Proiectul de azi. Jurnalul de măsurători.

Minim înseamnă: A notează temperatura în listă, B o citește pe rând, cu cel puțin opt blocuri diferite, pe placă. Complet înseamnă: minim, plus A și B care arată media și maximul măsurătorilor, cu cel puțin șase blocuri diferite. Dacă rămâi în urmă, oprește-te la minim și salvează. Ești la Minim când un coleg apasă A de trei ori și apoi B, iar placa îi arată cele trei temperaturi, pe rând.

Bonus. Schimbi pauza de la afișare și numărul de măsurători. Provocarea, Stația meteo: o stație meteo care măsoară singură. În Forever, o dată la zece secunde, notează temperatura în listă, până la șase măsurători. La A și B împreună placa arată Sus dacă ultima valoare este mai mare decât prima, Jos dacă este mai mică. Un coleg ține placa în mână un minut, iar placa trebuie să arate Sus.

Recapitulare. O listă ține mai multe valori într-o variabilă. Add value adaugă, Get value citește, Length numără. Prima poziție este zero, ultima este length minus unu. For index de la zero la length minus unu citește toată lista. Media este suma împărțită la cât sunt, maximul se găsește comparând pe rând.

Tema, opțional. Dacă ai doar Minim, adaugi acasă media și maximul. Dacă ai Complet, notezi temperatura camerei la cinci ore diferite, le scrii pe foaie ca jurnal și calculezi media cu mintea, apoi o compari cu placa.

Ce urmează. În lecția șapte faci un instrument muzical fără să-l atingi: un theremin cu lumină.
