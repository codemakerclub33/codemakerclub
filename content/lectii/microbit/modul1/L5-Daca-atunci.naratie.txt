Lecția cinci. Scutul de energie.

Astăzi înveți să faci placa să decidă și faci Scutul de energie: A încarcă scutul, B îl lovește, iar când energia ajunge la zero apare Game over. Fișierul se numește Prenume, linie jos, Nume, linie jos, M B unu, linie jos, L zero cinci.

Obiectivul. La finalul orei folosești If then și If then else și compari numere. Minim: A încarcă scutul, B îl lovește, iar când energia ajunge la zero, placa arată Game over și un craniu, apoi pornește iar de la cinci, cu cel puțin opt blocuri diferite. Complet: partea a doua, în care A încarcă scutul, dar niciodată peste nouă, iar A plus B arată starea scutului, cu cel puțin șase blocuri diferite.

De ce contează. Tu iei decizii tot timpul: dacă plouă, iau umbrela, altfel iau ochelarii de soare. Un program face la fel. Fără decizii, un joc nu poate spune ai pierdut, iar o alarmă nu știe când să sune.

Ce face fiecare bloc de azi. Din capitolul Logic folosim If then, care face ceva doar dacă condiția este adevărată. If then else face un lucru dacă este adevărat și altul dacă nu. Blocul egal compară dacă două numere sunt egale. Blocul mai mic compară dacă primul este mai mic. And este adevărat doar dacă amândouă condițiile sunt adevărate. Or este adevărat dacă măcar una este adevărată, îl folosim la Bonus. Din lecțiile trecute știi deja On start, On button pressed, Set, Change, Show number, Show string, Show icon și Pause.

Primul pas. Jocul Dacă atunci, cu cartonașe. Pe cartonașe scrieți câte o regulă: dacă plouă, atunci iau umbrela, altfel iau ochelarii de soare. Un copil citește o situație, altul alege cartonașul potrivit. Fiecare regulă are o condiție, care poate fi adevărată sau falsă, ce faci dacă este adevărată și ce faci dacă nu.

Al doilea pas. Condiții și comparații. În capitolul Logic găsești blocurile de comparat numere. Răspunsul este mereu adevărat sau fals. Dacă energie este patru, atunci energie egal cu patru este adevărat, energie mai mic decât patru este fals, energie mai mare decât doi este adevărat. Semnul egal din Logic întreabă dacă sunt egale. Set pune o valoare. Nu le amesteca.

Al treilea pas. Proiect nou și pornirea. Creezi variabila energie, ca în lecția patru. În On start pui Set energie la cinci și Show number energie.

Al patrulea pas. Scutul de energie, pentru Minim. A încarcă scutul cu unu. B îl lovește cu unu. Dacă după lovitură energia a ajuns la zero, jocul s-a terminat și pornește iar de la cinci. Altfel arată energia. La butonul A, Change energie cu unu și Show number energie. La butonul B, mai întâi Change energie cu minus unu. Apoi If then else, cu condiția energie egal cu zero. La atunci: Show string Game over, Show icon craniu, Pause o mie, Set energie la cinci, Show number energie. La altfel: Show number energie. Change vine înaintea lui If: întâi lovim scutul, apoi verificăm dacă a ajuns la zero.

Al cincilea pas. Complet. A nu trece de nouă. La A, energia crește cu unu, dar doar dacă este mai mică decât nouă. Așa scutul nu se încarcă la nesfârșit.

Al șaselea pas. Complet. A plus B arată starea scutului. Dacă energia este sub trei, placa spune Pericol. Dacă este peste șase, spune Plin. În rest, spune Mediu. Pentru asta punem un If then else în ramura Altfel a altuia.

Greșeli frecvente. Scutul nu ajunge niciodată la zero: Change este după If, nu înainte. Nu se întâmplă nimic la zero: ai scris energie în loc de energie egal cu zero, ai uitat comparația. Verifici egal cu Set: egal întreabă, Set pune valoarea. Energia trece de nouă: lipsește If energie mai mic decât nouă la A. A plus B arată mereu Mediu: al doilea If then else nu este în ramura Altfel a primului.

Proiectul de azi. Scutul de energie.

Minim înseamnă: A încarcă scutul, B îl lovește și la zero apare Game over, cu cel puțin opt blocuri diferite, pe placă. Complet înseamnă: minim, plus A care nu trece de nouă și A plus B care arată starea scutului, cu cel puțin șase blocuri diferite. Dacă rămâi în urmă, oprește-te la minim și salvează. Ești la Minim când un coleg apasă B de cinci ori și la a cincea placa arată Game over și craniul, apoi energia pornește iar de la cinci.

Bonus. Schimbi energia de start și vezi cât ține jocul. Provocarea, Scutul cu trei vieți: adaugi trei vieți, într-o variabilă numită vieti. La energie zero pierzi o viață, iar energia revine la cinci. Când vieți ajunge la zero, apare Game over final. Cu Or: dacă energia este sub doi sau mai ai o singură viață, la A plus B apare fața surprinsă. Un coleg joacă un minut și ghicește regulile din ce vede.

Recapitulare. Condiție înseamnă întrebare cu răspuns adevărat sau fals. If then face ceva doar dacă este adevărat, Else înseamnă altfel. Egal întreabă, Set pune o valoare. And cere amândouă adevărate, Or cere măcar una, le folosești la Bonus. Ordinea blocurilor contează: întâi Change, apoi If.

Tema, opțional. Dacă ai doar Minim, adaugi acasă limita lui A și A plus B. Dacă ai Complet, scrii pe foaie trei decizii din viața ta, în forma dacă, atunci, altfel, și alegi una pe care o faci cu blocuri.

Ce urmează. În lecția șase placa repetă lucruri cu bucle, într-un far de pe mare.

Succes la scutul tău.
