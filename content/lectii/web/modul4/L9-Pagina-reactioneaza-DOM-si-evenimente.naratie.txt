Lecția nouă. Pagina care reacționează: DOM și evenimente.

Până acum rezultatele programelor tale apăreau doar în consolă. Azi pagina ta însăși prinde viață: apeși un buton și se schimbă un text, scrii un cuvânt și apare într-o listă, apeși alt buton și pagina trece în modul noapte. Pentru asta înveți două lucruri: cum găsește JavaScript elementele paginii, adică DOM, și cum ascultă ce face utilizatorul, adică evenimente.

Ce facem azi. La final ai pagina ta cu trei lucruri noi, care funcționează în pagină, nu în consolă: un buton pentru modul noapte, un contor cu butoane și o listă la care adaugi fapte scrise într-un câmp. Aici se întâlnesc cele trei limbaje: H-T-M-L pune elementele, C-S-S le dă aspectul, iar JavaScript le face să reacționeze.

Instrucțiuni noi azi. Query selector găsește un element al paginii. Text content este textul din interiorul unui element. Add event listener rulează o funcție când apare un eveniment. Class list toggle adaugă sau scoate o clasă. Value dă textul scris într-un câmp. Create element și append child adaugă un element nou în pagină.

Pregătirea. Creezi folderul lecției ca o copie a folderului din lecția trecută și golești fișierul de script. În pagina ta pui un identificator pe titlu și adaugi un paragraf și un buton. Scriptul trebuie legat chiar înainte de închiderea corpului paginii, ca elementele să existe înainte să le cauți.

Primul pas. Browserul transformă pagina într-o structură cu elemente cuibărite, ca un arbore genealogic. Aceasta este DOM. Ca să lucrezi cu un element, îl găsești cu query selector, folosind un selector de C-S-S: diez pentru identificator, punct pentru clasă. Dacă selectorul este greșit, rezultatul este nimic, iar erorile apar mai târziu. Query selector all găsește toate elementele și le parcurgi cu for of.

Al doilea pas. Text content schimbă textul unui element, iar pagina se schimbă pe loc. Pentru text primit de la utilizator folosim întotdeauna text content. Inner H-T-M-L înțelege etichete și nu îl folosim cu text scris de utilizator, pentru că ar putea strecura cod rău intenționat.

Al treilea pas. Un eveniment este ceva ce se întâmplă în pagină: un click, o tastă apăsată. Add event listener spune unui element: când se întâmplă asta, rulează funcția. Funcția rulează doar când apare evenimentul, nu imediat. Dacă pagina nu se schimbă, citește mesajul roșu din consolă.

Al patrulea pas. Un contor ține minte valoarea într-o variabilă creată în afara funcțiilor. După ce schimbi variabila, actualizezi și textul din pagină, pentru că variabila nu se vede singură.

Al cincilea pas. Cea mai bună metodă de a schimba aspectul este să adaugi sau să scoți o clasă scrisă în C-S-S. Toggle o adaugă dacă lipsește și o scoate dacă există, ca un întrerupător. Astfel, stilul rămâne în C-S-S, iar JavaScript doar pornește și oprește clasele.

Al șaselea pas. Value este ce a scris utilizatorul în câmp și este întotdeauna text. Trim scoate spațiile de la început și de la sfârșit. Verifici dacă textul este gol înainte să-l folosești. Nu cere nume reale sau date personale.

Al șaptelea pas. Pentru a adăuga un element în listă, creezi un element cu create element, îi pui textul, îl lipești la sfârșitul listei cu append child, apoi golești câmpul și pui cursorul înapoi în el. Un return fără valoare oprește funcția mai devreme.

Mini-proiectul. Adaugi în pagina ta butonul pentru modul noapte, contorul de aprecieri și lista de fapte, apoi scrii scriptul cu cele trei părți. Contorul nu coboară sub zero, câmpul gol primește un mesaj, iar lista are o limită.

De făcut azi. Minim: un buton care schimbă un text. Complet: un contor, un buton care schimbă aspectul, un câmp și o listă, cu verificarea câmpului gol și comentarii.

Bonus. Culori care se schimbă la fiecare click, un buton care șterge ultimul element, tasta Enter pentru adăugare și un mesaj special când contorul ajunge la zece.

Greșeli frecvente. Scriptul este înainte de elemente. Selectorul este greșit. Ai pus paranteze la funcția din add event listener. Ai scris text content cu litere greșite. Ai uitat value la un câmp. Ai schimbat variabila, dar nu și pagina. Ai creat variabila contorului în interiorul funcției. Ai folosit inner H-T-M-L cu text de la utilizator.

Tema. Termini proiectul, refaci patru exemple și încerci două exemple de acasă: un buton care reacționează la mouse și numărarea elementelor din pagină. Mai ai patru exerciții, de la B până la E.

Recapitulare. DOM este structura paginii. Query selector găsește, text content schimbă textul, add event listener ascultă, iar class list toggle schimbă aspectul. Succes!
