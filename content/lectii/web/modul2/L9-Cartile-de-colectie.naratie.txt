Lecția nouă. Cărțile de colecție.

Uneori ai nevoie de o cutie în care să pui câteva lucruri, sau de o etichetă care să marcheze un cuvânt, iar niciun tag cu înțeles nu se potrivește. Pentru asta există div și span. Iar ca să le dai nume, folosești id și class. Cu ele faci cărți de colecție cu jocurile tale preferate.

Ce facem azi. La final ai o pagină cu cărți de colecție despre jocurile preferate: fiecare carte este o cutie cu chenar, titlu și o valoare, iar una este rară, cu fundal auriu. Știi să folosești div ca să grupezi lucruri și span ca să marchezi o parte dintr-un text, să dai nume cu id, care este unic, și cu class, care este refolosibil, și să folosești aceste nume într-o regulă de stil din head. Cu class poți face aceeași schimbare de aspect la zece elemente deodată, scriind regula o singură dată.

Instrucțiuni noi azi. Div este o cutie fără înțeles, care grupează lucruri. Span este o etichetă pentru o parte dintr-un text. Id este un nume unic pentru un singur element. Class este un nume pentru un grup de elemente. În stil, o clasă se scrie cu punct în față, iar un id cu semnul diez.

Primul pas. Div și span. Div este o cutie fără niciun înțeles, o folosești doar ca să grupezi un titlu și un paragraf care merg împreună. Dacă există un tag cu înțeles, îl alegi pe acela. Span marchează o parte din text, în interiorul rândului, în timp ce div se așază pe rând nou.

Al doilea pas. Id. Id este numele unic al unui singur element. Poate fi ținta unui link și poate fi folosit într-o regulă de stil. Fiecare id apare o singură dată în pagină, ca numărul de pe tricoul unui jucător.

Al treilea pas. Class. Regula cu punct se aplică tuturor elementelor cu acea clasă, așa că o scrii o singură dată. Clasa merge pe orice tag. Un element poate avea mai multe clase, separate prin spațiu.

Al patrulea pas. Mini-proiect. Id este pentru un singur element special, iar class pentru un grup de elemente care arată la fel. Numele au litere mici, fără spații și fără diacritice, cu liniuță între cuvinte, și spun ce este, nu cum arată. Apoi facem cărțile de colecție, cu o regulă pentru toate cărțile și una pentru cartea rară. În DevTools vezi clasele și regulile.

De făcut azi. Minim: trei cutii cu aceeași clasă, stilate printr-o singură regulă. Complet: adaugi un span cu clasă, un id pe titlul principal cu regulă proprie, o carte cu două clase și explici într-un comentariu diferența dintre id și class.

Bonus. Colecția cu grupuri. Adaugi o clasă pentru cărțile obișnuite, o cutie care conține toate cărțile, un link către titlu și schimbi regula direct în DevTools.

Greșeli frecvente. Ai scris numele clasei fără punct. Ai folosit semnul diez pentru o clasă. Același id de două ori. Nume cu spații sau diacritice. Ai uitat punct și virgula. Style pus în body. Div acolo unde exista un tag cu înțeles. Clase separate cu virgulă.

Tema. Cărți de colecție cu sporturi. Apoi refaci patru exemple, încerci două exemple pentru acasă și rezolvi încă patru exerciții.

Recapitulare. Div grupează, span marchează text, id este unic, class este pentru un grup. Succes!
