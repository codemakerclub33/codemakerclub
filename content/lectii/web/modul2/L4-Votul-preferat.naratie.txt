Lecția patru. Votul preferat.

Nu toate răspunsurile se scriu cu litere. Uneori alegi una dintre mai multe variante, alteori bifezi mai multe, iar alteori alegi dintr-o listă. Azi înveți toate aceste feluri de alegeri, pentru un sondaj despre sporturi.

Ce facem azi. La final ai o pagină de vot pentru sportul preferat, cu butoane rotunde, căsuțe bifate, o listă de alegere și câmpuri speciale pentru număr, culoare și valoare pe o scală. Alegerile sunt mai ușor de completat decât textul, și sunt mai sigure pentru cine face pagina, pentru că răspunsurile sunt cele pregătite de tine. În sondaje întrebăm despre lucruri, nu despre persoane. Nu cerem vârsta, adresa sau alte date personale.

Instrucțiuni noi azi. Tipul radio te lasă să alegi o singură variantă. Tipul checkbox te lasă să bifezi oricâte. Select cu option face o listă de unde alegi. Checked și selected pun o variantă aleasă de la început. Fieldset cu legend grupează întrebările într-un chenar cu titlu.

Primul pas. Butoanele rotunde. Toate variantele unei întrebări au același name, așa știe browserul că poți alege doar una. Fiecare variantă are alt id și altă value, iar eticheta are for egal cu id. Value este răspunsul care se păstrează, iar textul din etichetă este ce vede vizitatorul.

Al doilea pas. Căsuțele bifate. Poți bifa oricâte. Fiecare variantă bifată apare în adresă la trimitere. Radio este pentru o singură alegere, checkbox pentru mai multe.

Al treilea pas. Lista de alegere. Select este lista, iar fiecare option este o variantă. Prima opțiune goală este un îndemn, de exemplu alege o zi. Lista este bună când ai multe variante.

Al patrulea pas. Grupuri și câmpuri speciale. Fieldset desenează un chenar, iar legend este titlul lui și se pune imediat după fieldset. Câmpul number primește doar numere, color este o paletă de culori, iar range este un cursor care se mută între minim și maxim.

Al cincilea pas. Votul complet. Pentru una din mai multe variante folosim radio sau select, pentru oricâte folosim checkbox. Apoi construim pagina votul preferat, o dată completată o trimitem și citim răspunsurile în adresă.

De făcut azi. Minim: o întrebare cu radio, una cu checkbox și una cu select. Complet: adaugi grupuri, un câmp special, o variantă aleasă de la început, butoanele de trimitere și de ștergere, și notezi răspunsurile din adresă.

Bonus. Votul cu sugestii. Încerci lista cu alegere multiplă, un cursor cu pași și faci un sondaj complet despre articolul tău de pe Wikipedia.

Greșeli frecvente. Radio cu nume diferit. Același id la mai multe casete. Lipsește value. Checked pe mai multe variante. Legend care nu este primul în fieldset. Etichete nelegate. Date personale cerute.

Tema. Un formular alege aventura ta. Apoi refaci patru exemple, încerci două exemple pentru acasă și rezolvi încă patru exerciții.

Recapitulare. Radio pentru una, checkbox pentru mai multe, select pentru o listă, fieldset pentru grupuri. Succes!
